# scopa

Scopa is a classic italian card game

## Description
In scopa there are four types of cards: ‘Spade‘, ‘Ori‘, ‘Coppe‘ and ‘Bastoni‘ (In the
Bergamasca version, other regions have different card styles, and in some cases, different
names). 

## How to play
This game can be played in 2 or 4 (divided in 2 groups). At the start each player gets 3 cards, and
4 cards are laid on the table. To win, a player must have more points than the other, to get
points there are criteria to meet:
1. Have more cards than the adversary
2. Have the seven of ‘Ori‘
3. Have more ‘Ori‘ than the adversary
4. Have more cards of the number seven than the adversary, if both have 2, this point
will not be assigned
5. Each ‘Scopa‘ is a point, a ‘scopa‘ is when a player clears the table of cards
To get a card, the player must lay on the table a card with the same value of one, or the
value of the sum of two or more cards. The value for each card is: From left to right 1 to
10

## How to win
At the end the number of cards is counted, and who has more points wins
